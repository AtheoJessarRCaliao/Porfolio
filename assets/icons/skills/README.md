# Technical Skills icons

These SVG files are served locally so skill badges do not depend on an external icon CDN.

- Technology logos (except Render): [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons), original SVG variants; Django uses the plain variant. See `LICENSE-devicon.txt`.
- Render: [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/render.svg), downloaded 2026-09-29. See `LICENSE-simple-icons.md`.
- The 14 generic icons for database, responsive design, APIs, schemas, architecture, networking, and professional skills were created for this portfolio.

Logos identify the listed technologies; their names and trademarks belong to their respective owners.
